What the street showed

We filmed 62 sampled block faces on three weekday mornings and checked every candidate frame by hand. We found 9 double-parking events over 14.2 km of curb driven past.

Blocks with more businesses had about four times the double parking of quieter blocks. Blocks the model calls short of loading space did not have clearly more.

Read the map with care

The shortage map is a model, not a count. Nine events is a small sample, so the test could not rule out a real effect of curb supply. A plain count of businesses predicted double parking as well as the full model. Treat the map as a way to compare blocks and test ideas, not as a measured truth.
